# Code of conduct

LongHorn follows the [Contributor Covenant, version 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be respectful and assume good faith. Harassment and personal attacks are not
accepted in issues, pull requests, discussions or any other project space.

To report a problem, contact the maintainer through the GitHub profile
[MirHamzaHasan](https://github.com/MirHamzaHasan). Reports are handled privately. The
maintainer may remove content or block people who break these rules.
